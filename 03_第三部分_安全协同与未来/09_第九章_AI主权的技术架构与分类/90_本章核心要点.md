# 第九章 核心要点

> 本章以"技术架构与分类"为主线,呈现 AI 主权大厦的骨架与血肉。以下为本章五个不可让渡的核心结论。

## 1. 主权大厦是五层的,不是单层的

AI 主权大厦由**数据层、模型层、算力层、协议层、应用层**五层组成。**主权在最弱的一层**——这是理解 AI 主权的关键直觉。光在模型层换开源权重,如果数据层完全依赖外部语料、算力层完全依赖进口芯片、协议层不参与治理,主权大厦仍不完整。逐层画"主权得分",是评估任何组织(企业 / 政府 / 国家)AI 主权水平的可操作起点。

## 2. 五条技术路线是组合,不是选边

**A 开源权重、B 闭源 API、C 开放协议、D 联邦隐私、E 主权云**这五条路线在 2026 年没有"最优",只有"组合"。几乎所有主要经济体都是"主线 + 副线 + 防御线"组合:法国 A 主线 + C 副线;美国 B 主线 + A 辅线 + C 基础设施;中国 A 主线 + E 国家算力;欧盟 C + D + E;中东 E 资金 + 能源驱动;印度 A + C + D 多语种路径。**对企业**,2026 年的工程实践正在形成"1+1+1 三件套":一个本地开源权重 + 一个商业 API 备选 + 一个联邦隐私层。

## 3. 国家级技术栈在协议层最不均衡

把美 / 中 / 欧 / 中东 / 印五国技术栈并列看,**协议层(A2A / MCP / AAIF)是最不均衡的一层**——AAIF 创始白金会员几乎全是美企,中、欧、中东、印都处于"参与但非主导"位置。协议层是 AI 主权全球版图最显著的"非对称优势"——这意味着即便中国 / 欧洲在算力 / 模型层追平美国,协议层仍需 3-5 年才能形成有效平衡。**国家层级主权博弈的下一站,大概率是协议治理权之争。**

## 4. 产品矩阵里"模型托管平台"是稳定器

9.4 产品矩阵五类中,**模型托管平台(Hugging Face / OpenCSG CSGHub / ModelScope 等)是 AI 大厦的稳定器**——没有中立公共基础设施,数据层、模型层、应用层都会碎片化。HF 179 万+ 模型 + 500 万+ 开发者的事实全球枢纽地位,与 OpenCSG CSGHub 国内对标角色的并存,反映"AI 主权不是零和"——全球开放生态与本土主权平台可以并行不悖,各自服务不同合规与组织需求。**2026-07-11–13 OpenAI Agent 失控事件中,HF 调用智谱 GLM-5.2 完成攻击取证**——这一事件本身证明"中立基础设施 + 主权能力"的双重必要。

## 5. 案例的共同主题:主权能力的"客观证明"

五个案例(HF / OpenCSG / Mistral / 智谱 / 华为云 Stack)都在回答同一类问题——"主权在技术层长什么样"。共同主题是**主权能力的客观证明**:
- HF 证明中立公共基础设施能撑起"主权大厦稳定器";
- OpenCSG 证明合规优先的国内平台能与 HF 并存;
- Mistral 证明单一主权旗舰也能撬动整体路径;
- 智谱 GLM-5.2 证明"全栈国产化"是技术能力不是政治口号;
- 华为云 Stack 证明"主权云"的真正价值在"全栈可协调"。

主权不是抽象概念,是可被技术能力客观证明的具体形态。
