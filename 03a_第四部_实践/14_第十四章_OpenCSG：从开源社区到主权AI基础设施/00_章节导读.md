# 第十四章　OpenCSG：从开源社区到主权 AI 基础设施

二〇二六年九月三日，英伟达确认以约一百二十九亿美元收购 Hugging Face，交易还要等监管审批。黄仁勋承诺平台继续向整个生态开放，在上面开发和部署不必用英伟达的芯片。[^new-nvidia-hf] 对每天从 Hugging Face 下载模型的开发者来说，那天什么也没变，模型照样能下，接口照样能用。变的是一件更远的事：全世界最大的开放模型仓库，今后的路线由一家芯片公司来定。

开源社区平时像空气，很少有人把它当成谁的资产。一个团队找模型、比许可证、下载权重、上传自己微调过的版本，靠的都是社区提供的目录、版本记录和下载通道。这些通道集中在少数几家平台手里的时候，社区本身就成了一块基座。第三章讲六大基座时说过，每一块基座都要问一句：它靠的是谁，靠不住的时候怎么办。

OpenCSG 就是在这样的背景下做起来的。它在 GitHub 上的自我介绍是“二〇二三年成立的一项开源、公平的倡议，致力于为大模型建设开放社区”，主要代码以 Apache-2.0 许可证（一种允许商用、修改和再发布的宽松开源许可证）公开。[^p17-opencsg-org] 二〇二四年一月的报道称，它的社区当时上线了一百多个精选模型和六十多个数据集；投资界二〇二六年八月报道它完成数亿元 Pre-A 轮融资时，援引公司的说法，平台已有二十多万个模型、两万多个数据集，累计连接三百九十多万名开发者和用户。[^p17-opencsg-scale] 这些都是公司自报的数字，前后统计口径也不一样，没有第三方核实过。

社区只是第一层。一家企业要把公共社区里的模型变成自己管得住的能力，还要在社区外面补上几层东西。
