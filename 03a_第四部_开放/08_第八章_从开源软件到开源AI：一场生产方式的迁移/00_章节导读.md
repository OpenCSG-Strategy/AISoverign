# 第八章　从开源软件到开源 AI：一场生产方式的迁移

二〇二三年八月十日，美国基础设施软件公司 HashiCorp 宣布，旗下产品今后的新版本不再使用 Mozilla 公共许可证 2.0（MPL 2.0，一种允许自由修改和再分发的开源许可证），改用商业源代码许可证（Business Source License，BSL）1.1。影响最大的是 Terraform，一个用代码来描述和管理云上服务器、网络和数据库的工具，从二〇一四年起一直以 MPL 2.0 开源，许多云服务和运维平台都建在它上面。新许可证仍然允许普通用户免费使用和修改，但不许用在和 HashiCorp 构成竞争的商业服务里，这类竞争者今后拿不到新版本、漏洞修复和安全补丁。[^p8-hashicorp-bsl]

几家靠 Terraform 做生意的公司联名发表公开信，请 HashiCorp 收回决定，没有改变结果。他们于是拿许可证变更以前的开源代码另起炉灶。九月二十日，这个分叉项目定名 OpenTofu，由 Linux 基金会（Linux Foundation，托管 Linux 等大量开源项目的非营利组织）接手托管，一百四十多家机构和七百多名个人表态支持。二〇二四年一月十日，OpenTofu 发布了第一个正式版本，Terraform 的用户可以比较顺利地切换过去。[^p8-opentofu]

HashiCorp 有权决定自己以后怎样卖产品。它没法做到的，是让用户从此只能跟着它走。已经以 MPL 发布的代码收不回来，社区里有足够多懂这套代码的工程师，再加上一家中立的基金会愿意出面，分叉就成立了。

开源在主权问题上的分量，在这种时候看得最清楚。到了 AI 时代，一个系统除了代码，还有权重、训练数据和评测方法，“开源”这个词也跟着变得复杂起来。
