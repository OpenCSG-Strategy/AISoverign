# 《AI主权：在机器时代保留选择的能力》

> 当机器越来越会思考，人类如何保留选择与自由？

中文书籍《AI主权》的草稿仓库，由 Frank Chen 主理。仓库里的拆分目录是唯一正文来源；旧版十章稿只保留在 Git 历史中，需要时可以从那里取材。

本书的核心判断只有一句：

> **AI主权不是完全自给自足，而是在深度相互依赖中保留选择权。**

## 阅读路径

按 `.content-index.md` 的章节顺序读，全书沿“生产 → 行动 → 责任”三条线推进：

1. **书前**：先提出全书问题，再交代证据边界。
2. **序章　智能权力的重新分配**：在历史尺度上看认知与行动的工业化、能力扩散与控制集中，以及 OPC 带来的组织变化。
3. **第一部　当AI成为基础设施**
   - 第一章：Token、训练、推理、芯片与能源，说明能力是怎样被生产出来的。
   - 第二章：模型怎样离开工厂，经蒸馏、开放、本地或云端部署进入能力网络。
   - 第三章：从会回答的模型走到会行动的系统，定义可治理委托、六种能力、四个尺度的责任链和最低可行主权。
   - 第四章：AgenticOps，用三个循环加一个共同控制面管理会行动的 AI。
4. **第二部　主权是建出来的**：个人（第五章）→ 组织单元（第六章）→ 企业（第七章）→ 国家与城市（第八章）。四章讲的是同一种结构在四个尺度上的放大，不是四个互不相干的主题。
5. **第三部　在依赖中争取自由**：依赖怎样不变成支配（第九章），开放的力量和代价（第十章），协同与 AI 原生组织（第十一章）。
6. **结语　把选择留在自己手里**：把三条线收拢，给出理论反例和面向未来的检验。

时间不够的读者可以先读 **序章 → 第三章 → 第四章 → 结语**，抓住主线，再挑自己所在的尺度（第五至八章之一）深读。

## 核心论点

### 一、六种可以检验的能力

主权不看声明，要看动作能不能真正发生。全书用六种能力来检验主权（第三章 08 节）：

| 能力 | 检验的问题 |
|---|---|
| 选择 | 能否看清不同方案的成本、条件与风险，并按自身目标决定路径 |
| 替换 | 条件变化后，经过演练的备选系统能否接手，保证关键能力不归零 |
| 迁移 | 知识库、提示、评测集、权限关系等智能资产能否被带走 |
| 审计 | 模型之外是否留有证据：输入、版本、检索、工具调用、授权、人工确认 |
| 组合 | 能否让强模型、小模型、确定性程序、规则和人各自承担合适的部分 |
| 演进 | 系统能否随环境变化持续改进，而不是锁死在某一次采购上 |

### 二、OPC 集聚：同一种结构，四个尺度

个人、组织单元、企业、国家与城市不是四类并列的主权，而是**同一种 OPC（一人公司）组织方式沿责任半径持续放大的四个读数**：一人公司是最小的尺度，部门是它在同一屋檐下的重复，企业是它在法人边界上的放大，城市与国家则是无数 OPC 在公共尺度上集聚后长出来的。尺度变大以后，变的是责任半径、治理主体和救济渠道，机制本身不变（序章 04、07 节，第三章 09 节，第十一章 02 节）。

### 三、五根桩

组织单元这一尺度的主权落在五根共享构件上（第六章 08 节）：

- **身份**：谁或哪个智能体正在行动，带着谁的授权
- **权限**：可以访问的数据、可以调用的工具、可以触发的动作
- **审计**：行动、版本、批准和制品都可以还原
- **降级**：主服务、模型或供应商中断时有回退路径
- **演练**：压力场景在受控条件下定期走一遍

第八章把五根桩映射到城市与国家的具体形态，比如身份对应法人登记，权限对应行政许可。

### 四、双三权

企业这一尺度的两条权利线（第七章 08 节）：

- **数据三权**：所有、使用、删除。管数据权属，对应第六章 03 节的最小披露契约。
- **授权三权**：知情、申诉、替换。管服务责任。

第八章 11 节把双三权放到城市与国家尺度上，并用澳大利亚 Robodebt 作为反面案例。

### 贯穿全书的方法：AgenticOps

六种能力和四个尺度的责任链回答“主权是什么”，AgenticOps 回答“怎样让它每天运行”：交付、运行、学习三个循环，加上一个共同控制面。两者是同一套东西，不是两套互相竞争的理论。

## 索引入口

接手这个仓库的人或 AI，请先看索引，不要从头通读全书：

| 索引 | 用途 |
|---|---|
| `.content-index.md` | 每章的核心任务、路径与最近状态 |

协作规范（提交流程、脚注规则、已知陷阱）见 `AGENTS.md`；改写方法见 `90_出版工作台/03_全书提质改写手册.md`，其中第八章是验收过的样板章。

### 写进书稿的事实须标三样

- **截至日期**（YYYY-MM-DD）
- **来源 URL 与媒体**，优先级为一手来源 > 权威转述 > 二手报道
- **置信度**：已确认 / 多源一致 / 待确认 / 单一来源

脚注在正文中使用 `[^pX-*]` 编号，统一定义在 `05_附录/附录B_精选尾注.md`，不允许悬空，也不允许重复定义。
