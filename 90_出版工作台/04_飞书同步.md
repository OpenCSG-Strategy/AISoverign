# 飞书同步

书稿以本仓库为准。每次有改动推送到 `main`，GitHub 上的“同步到飞书”任务会把全书组装好，整篇覆盖写入同一个飞书文档，二十三张图也一起上传，文档链接保持不变。

同步是单向的：在飞书里直接改的内容，下次同步时会被覆盖。飞书上的同事请用评论提意见，再由仓库这边改稿。

## 第一次配置

1. **建一个飞书自建应用。** 在飞书开放平台（open.feishu.cn/app）创建“企业自建应用”，在“权限管理”里开通下面几项权限，然后发布版本，等管理员审核通过。
   - 查看、编辑和管理新版文档（`docx:document`）
   - 文本内容转换为云文档块（`docx:document.block:convert`）
   - 上传图片和附件到云文档中（`docs:document.media:upload`）
   - 如果目标文档在知识库里，再加上：查看知识库（`wiki:wiki:readonly`）
2. **准备目标文档。** 在飞书新建一篇空白文档，也可以是知识库里的一页。点击右上角“…”，选择“更多 → 添加文档应用”，把上一步的应用加进来，给它“可编辑”权限。
3. **把密钥存进 GitHub。** 打开仓库的 Settings → Secrets and variables → Actions，新建三个 Repository secret：
   - `FEISHU_APP_ID`：应用的 App ID
   - `FEISHU_APP_SECRET`：应用的 App Secret
   - `FEISHU_DOC`：目标文档的完整链接
4. **跑第一次。** 在仓库的 Actions 页面打开“同步到飞书”，点 Run workflow。以后每次推送都会自动运行。

使用国际版 Lark 时，再加一个 secret：`FEISHU_BASE`，值为 `https://open.larksuite.com`。

## 文档里会有哪些变化

- 飞书不支持脚注，正文里的脚注标记改成“［1］”这样的序号，注释原文留在各章末尾原来的位置，也换成同样的序号。
- 每张图下面加一行图题。
- 文档开头有一行说明，写着最后一次同步的时间和对应的提交。

## 在本地检查

`python3 tools/feishu_sync.py --dry-run 输出.md` 只生成准备上传的 Markdown，不连接飞书，可以用来检查转换结果。
