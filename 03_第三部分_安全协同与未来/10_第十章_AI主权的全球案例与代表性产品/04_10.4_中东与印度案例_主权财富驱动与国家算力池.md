# 10.4 中东与印度案例:主权财富驱动与国家算力池

中东与印度代表了主权 AI 的两种"非西方非中国"路径:**资源型国家靠主权财富基金驱动的"中立枢纽"模式,印度靠国家级算力池 + 本土模型 + 公共数据三件套的"性价比主权"模式**。前文 1.3 已详述了 HUMAIN、Stargate UAE、Visakhapatnam 1 GW 等项目的核心数据;10.4 的视角切换到这三个项目在 5–7 月窗口内的**"分工机制"与"产业含义"**。

## 案例 1:沙特 HUMAIN 770 亿美元 + 11 个数据中心——"中立枢纽"的产业分工

沙特公共投资基金(PIF)牵头的国家数据与 AI 投资规模超过 **770 亿美元**,对应 **11 个超大规模 AI 数据中心规划**(延续此前 2.2 GW 装机口径)。配套产业由沙特电信(stc)、Aramco Digital、Saudi Data 与多家美 / 欧云厂协同推进[^ch13-28]。

5–7 月窗口内最值得关注的信号是: **NVIDIA 与 HUMAIN 之间在公开渠道未新增可验证 MOU**。这说明沙特项目在 2025-11 AWS × HUMAIN 签 15 万颗 AI 加速芯片(GB300 + Trainium)后已进入执行期,2026 年内更多表现为"既有协议落地"而非"新签扩张"[^ch13-29]。

"中立枢纽"模式的产业含义可拆为三层:
- **资金侧**:主权财富基金(PIF)作为单一最大出资方,采用国家资本直接下场的方式——这与欧洲 Mistral 8.3 亿欧元债务融资形成鲜明对比,沙特不需要"债务",可以直接"股权"。
- **技术侧**:HUMAIN 不锁定单一技术供应方,AWS、Aramco Digital、Saudi Data 与多家美 / 欧云厂各自承担不同角色(云、AI、能源、数据)——这种"分工而非整合"的产业组织,使得沙特可以同时与美中两国维持合作。
- **地缘侧**:**"中立枢纽"是一种主动选择,不是被动结果**。沙特与阿联酋都同时接入美国(Stargate UAE 联合体含 NVIDIA / OpenAI / Oracle / Cisco / SoftBank)与中国(华为 / 阿里在沙特云市场均有合作)——其 AI 主权路径的关键不是"哪一边",而是"两边都要"。

## 案例 2:阿联酋 Stargate UAE 5 GW 园区 + G42——"两头下注"的产业实证

阿联酋 G42 主导的 Stargate UAE 是 5–7 月窗口内全球**少数能拿"GW 级在建 + 2026 上电"双指标的主权 AI 项目**:5,000 MW 园区总规划,由 G42 + Khazna Data Centers + OpenAI + Oracle + NVIDIA + Cisco + SoftBank 联合体运营,**首期 200 MW 集群预计 2026 年内投运**[^ch13-30]。

"两头下注"模式的产业含义有三:
- **与美国**:5,000 MW 联合体里有 OpenAI(模型)、Oracle(云)、NVIDIA(算力)、Cisco(网络)、SoftBank(资本)——美国 5 家头部企业都参与其中,与美国 2025-05 框架(500 亿美元 AI 园区)一脉相承。
- **与中国**:G42 与中国企业的合作并未因 Stargate UAE 而中断——其与阿里云、华为云在阿联酋本地市场的合作仍有持续。
- **与本地**:Khazna Data Centers 作为阿联酋本土数据中心运营商承担"主权载体"角色,主权资本通过 G42(阿布扎比主权基金 Mubadala 投资)掌握控制权。

这种"5+5"结构(美中 5 + 5 头部企业 + 1 个主权基金载体)使阿联酋成为"两头下注"模式的产业样本。**5–7 月窗口内无重大新公告,但 Stargate UAE 是 2026 年内"投运"概率最高的非美国 GW 级项目**——其进度将直接影响"中立枢纽"模式的可行性。

## 案例 3:印度 IndiaAI 38,000 GPU + Adani 1 GW + Sarvam C 轮——"性价比主权"的三件套

印度的"性价比主权"模式由三个相互支撑的组件构成,前文 1.3 已逐一介绍[^ch13-31][^ch13-32]。10.4 关注的是这三个组件在 5–7 月窗口内的"产业协同机制":

- **国家级算力池**(IndiaAI 38,000 GPU 公共算力):Hyperscaler + 印度本土云厂按州/城市分批承接。5–7 月期间持续推进,但 2026-05–07 的"具体新增 GPU 交付数 / 已上线数"在公开渠道未拿到精确数字,只有累计合同总数。
- **GW 级基础设施**(AdaniConneX + Google Visakhapatnam AI Hub):1,000 MW 园区,2026-04-28 破土动工,Google Cloud / Adani Enterprises / Nxtra by Airtel 联合运营,印度本土首个 GW 级主权 AI 数据中心。
- **本土模型合作**(Sarvam Series C,7-16 完成):SoftBank Vision Fund 领投,Claypond Capital / Creaegis / Sentinel Global / YC / Khosla / Lightspeed 参投——是 5–7 月期间印度主权 AI 的**最高量级单一融资事件**。

三件套的协同机制是:
- **算力租赁代替采购**:用"国家级算力租赁"代替"国家级 GPU 采购",把 38,000 GPU 公共算力池作为一个公共服务平台,降低主权模型训练的资金门槛。
- **本土模型合作代替全栈自研**:用"本土模型合作伙伴"(Sarvam)代替"全栈自研",通过资本扶持 + 国家级算力优先接入,快速建立"主权模型"。
- **公共数据 + 开源生态降低训练成本**:IndiaAI 推动的"AIKosh"数据集(印度语言、政府数据、农业数据)与 Hugging Face 印度分中心合作,把"主权数据"与"开源生态"绑定,降低本土模型的训练数据获取成本。

**这种"轻资产 + 三件套"模式与中东的"基金驱动"形成鲜明对比,也与中美的"全栈自研"路径不同**。它给金砖国家中"无法承担 GW 级数据中心 + 万亿 GPU 采购"的国家(如越南、印尼、巴西)提供了一个可借鉴的样本。

## 小结

三个案例共同呈现了 2026 年中"非西方非中国"主权 AI 路径的产业多样性:
- **沙特**:主权基金 + 11 个 DC + 既有协议执行期,"中立枢纽"模式
- **阿联酋**:5 GW 园区 + 5+5 头部企业联合体,"两头下注"模式
- **印度**:国家级算力池 + GW 级基础设施 + 本土模型合作,"性价比主权"模式

**这三种模式与欧洲的"规则塑造者"、中美的"全栈自研"一起,共同构成 2026 年 AI 主权实践的"五种典型路径"**。本书第十二章的"未来 12 个月观察清单"将基于这些模式做产业对照分析。
