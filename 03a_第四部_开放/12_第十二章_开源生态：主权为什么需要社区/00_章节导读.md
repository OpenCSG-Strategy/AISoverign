# 第十二章　开源生态：主权为什么需要社区

二〇二二年九月十二日，Meta 把自己开发的深度学习框架 PyTorch 交给了 Linux 基金会，成立 PyTorch 基金会。创始理事会里除了 Meta，还有 AMD、亚马逊云科技、谷歌云、微软 Azure 和英伟达。Linux 基金会的说法是，一个有望成为关键技术底座的项目，放在一个不属于任何厂商的中立机构里更有利，治理也更透明。[^p12-pytorch-foundation]

PyTorch 当时已经被大量研究机构和公司使用，Meta 完全可以继续自己管着它。交出去以后，Meta 少了一些控制，竞争对手们却更愿意往里投入：芯片公司愿意为它做适配，云厂商愿意把它当默认选项，开发者也不必担心哪天它变成某家公司的专属工具。

三年以后，同样的事情发生在智能体领域。二〇二五年十二月九日，Linux 基金会宣布成立智能体 AI 基金会（Agentic AI Foundation），Anthropic 交出了模型上下文协议 MCP，金融科技公司 Block 交出了智能体框架 goose，OpenAI 交出了给编程智能体写说明的 AGENTS.md 规范。亚马逊云科技、谷歌、微软、彭博社、Cloudflare 等公司是白金会员，Hugging Face 也在会员名单里。[^p12-aaif] 第二章讲过 MCP 的来历，它从一家公司发起的接口，变成了竞争对手们共同管理的公共标准。

这几家公司彼此竞争得很激烈，却愿意把关键的底层部件放进同一个公共机构。底层部件只有大家都用、都信得过，才能成为标准；成了标准，每家公司在上面做自己的生意都更省力。
