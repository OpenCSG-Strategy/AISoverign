# 第八章　多模型：不押注唯一的模型

二〇二五年八月七日，OpenAI 发布 GPT-5，ChatGPT 里原来的 GPT-4o 被直接换了下去，用户登录以后找不到换回去的办法。反弹来得又快又响。不少人说新模型更冷淡、更机械，有人在 Reddit 上把失去 GPT-4o 比作“失去一个信得过的朋友”，也有人在 X 上说不恢复就退订。第二天，OpenAI 首席执行官萨姆·奥尔特曼（Sam Altman）发帖承认，“我们确实低估了人们有多在乎 GPT-4o 的一些特点”，随后让付费的 Plus 用户可以重新选回 GPT-4o。[^p11-gpt4o-restore] 这次恢复维持了半年。二〇二六年一月二十九日，OpenAI 宣布二月十三日在 ChatGPT 里下线 GPT-4o、GPT-4.1 等四个模型，理由是每天只剩百分之零点一的用户还在选 GPT-4o；接口（API）这一侧暂时不变。[^p11-gpt4o-retire] 从宣布到下线，中间只有十五天。

对个人用户，这是习惯和感情的事。对一家把某个模型写进了几十个业务流程的公司，换模型意味着每个提示词要重新调，每种输出格式要重新验，客户看到的回答也可能跟着变样。

模型不下线，也可能悄悄变化。二〇二五年九月，Anthropic 发布了一份事后复盘，承认八月初到九月中旬，三个互不相关的基础设施故障让一部分 Claude 回答的质量下降。一个路由错误把部分请求发到了为一百万 token 长上下文准备的服务器上，最严重的一个小时里影响了 Claude Sonnet 4 百分之十六的请求；一处配置错误让回答里偶尔冒出不相干语言的字符；一个编译器缺陷影响了模型挑选下一个 token 的环节。用户八月初就开始抱怨，公司起初很难把这些反馈和正常的波动分开，到八月底才正式调查，修复一直持续到九月十八日。Anthropic 强调它从不因为需求、时段或服务器负载降低模型质量，并表示今后要在真实的生产系统上持续做质量评测。[^p11-anthropic-postmortem]

第三章讲过 Windsurf 的遭遇，模型厂商只提前不到五天通知，就大幅削减了它的调用容量。下线、变化、断供，是押注单一模型的企业迟早会碰到的三种情况。
