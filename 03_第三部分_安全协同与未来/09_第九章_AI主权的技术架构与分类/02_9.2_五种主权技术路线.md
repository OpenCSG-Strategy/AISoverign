## 9.2 五种主权技术路线

### 路线不是选边,而是组合

第二章 2.3 讨论过"模型选型"——那是从"产品维度"看主权;本节从"国家/组织技术战略维度"看主权。**技术路线**(sovereignty path)指的是一个国家或组织在 AI 基础设施上的"主要押注方向"。截至 2026-07,全球主要经济体可归为五条路线:**A 开源权重路线**、**B 闭源 API 路线**、**C 开放协议路线**、**D 联邦 + 隐私计算路线**、**E 主权云 / 本地化路线**。

现实中的国家/组织通常不是单一押注,而是"主线 + 副线 + 防御线"组合。法国 Mistral 是 A 主线 + C 副线;美国 OpenAI 是 B 主线 + C 副线(2026-07-25 加入开放权重联名信后才开始试探 A);中国大模型厂商以 A 主线为主,但 B(API 服务)与 E(华为云 Stack)仍是商业落地关键。

### 路线 A:开源权重路线

**核心主张**:模型权重公开下载、可本地部署、可微调、可二次分发,主权在最弱主体(个人/中小企业)手里。

**代表玩家**:Meta Llama 4 Maverick(Apache 2.0 与 Llama 社区许可)、Mistral Large 3(Apache 2.0)、DeepSeek V4-Pro/MIT)、Qwen3-235B-A22B(Apache 2.0)、智谱 GLM-5(MIT)、Kimi K2.5 → K3(MIT 路线)、百川 Baichuan 4(7B/13B/53B 开源)、零一万物 Yi-Lightning 2、AI2 OLMo 3(完全开放:权重+训练数据+训练代码+评估代码)[^ch12-9][^ch12-10][^ch12-11][^ch12-12]。

**2026-07-24 节点**:NVIDIA 黄仁勋联合 25 家美企(至 7-25 增至约 35 家含 OpenAI)发表《Open Weights and American AI Leadership》公开信,首次把"开放权重"从技术议题推到美国国家产业政策层面;Anthropic 是最显眼缺席者,因 2 月指控 DeepSeek/ 月之暗面"蒸馏" Claude 与联名信"合法蒸馏不应一刀切"立场直接冲突[^ch12-3][^ch12-13]。

**适用场景**:科研机构、教育、初创公司、需定制化的企业、强调自主可控的国家。
**局限**:大模型训练成本极高,中小玩家难以独立维护基础模型,长期依赖少数头部开源厂商的"上游治理";运维、安全更新、合规审计仍需自建能力。

### 路线 B:闭源 API 路线

**核心主张**:模型权重不公开,通过 API 调用获取推理服务,主权集中在模型提供方。

**代表玩家**:OpenAI(GPT-5.6 系列、gpt-oss 试水)、Anthropic(Claude Opus 4.8 / Claude Fable 5)、Google Gemini 3、xAI Grok 4、阿里通义(API 商业版)、百度文心(API 商业版)。

**API-as-Sovereignty 的悖论**:API 路线看起来让用户省去训练和运维负担,但代价是**主权债大幅积累**——数据出境、审计难、定价权在提供方、突发封号风险(类似 2025 年中芯国际被列入实体清单后 NVIDIA H20 出口受限,使用 NVIDIA 闭源 API 的中国客户面临断供)。这一悖论在 2026 年驱动了大量"API 难民"——企业从纯 API 切换到混合(API + 自托管开源)。

**2026-07-25 节点**:OpenAI 延迟一天后加入开放权重联名信,被外界解读为"对纯闭源厂商生态孤立压力的妥协";OpenAI 同步发布 gpt-oss 系列(20B/120B)试水开源路线[^ch12-14]。这一动作本身证明纯 B 路线在 2026 年面临合法性压力。

**适用场景**:对模型能力要求极高、不愿自建运维、合规要求允许数据出境的场景。
**局限**:数据出境、封号风险、定价权丧失、监管合规难。

### 路线 C:开放协议路线

**核心主张**:不押注某一模型或某一云,而是押注**协议层中立与互操作**——MCP 解决"Agent ↔ 工具"、A2A 解决"Agent ↔ Agent"、AAIF 提供治理框架(详见 8.1)。

**代表玩家**:Linux Foundation AAIF(2026-04 成立,统一管理 A2A、MCP、Agent Safety 等协议族,创始白金会员:Google、AWS、Microsoft、IBM、Oracle、Cisco、Anthropic、OpenAI)[^ch12-8];Anthropic(MCP 创始方);Google(A2A 创始方);LangChain(LangGraph 编排);Microsoft(AutoGen 编排)。

**2026 节点**:A2A 支持组织超 150 家,MCP 月 SDK 下载量 9,700 万次,社区服务器超 8,600 个(详见 8.1)。开放协议路线本质是"**协议中立即主权**"——只要协议层开放,任何模型、任何云、任何 Agent 都能互操作,主权大厦不至于被某一层锁死。

**适用场景**:跨国组织、多云架构、需要快速组合多家厂商能力的场景。
**局限**:协议本身不解决数据出境、合规等问题;协议治理权仍集中在少数白金会员手中。

### 路线 D:联邦 + 隐私计算路线

**核心主张**:数据不出域,通过联邦学习、安全多方计算、差分隐私等技术实现"可用不可见"。

**代表玩家**:微众银行 FATE 框架(2026 持续演进);中国银联《金融业隐私计算互联互通平台技术规范》;IBM / Intel(跨工厂联邦学习专利布局);礼来 LillyTuneLab(2025-2026 含超 10 亿美元专有数据的联邦模型);欧盟 GAIA-X 180+ 数据空间(详见 8.2)。

**2026 突破**:AIFL-OS v3.2 将跨域训练通信开销降低 68%、跨域收敛加速 4.3 倍、审计可验证性达 NIST SP 800-193 Level 3 标准(详见 8.2)。金融领域中国银联联合工行、建行、招行构建跨行反欺诈联邦网络,模型对"信用卡套现团伙"识别准确率较单家银行提升约 18%。

**适用场景**:医疗(罕见病联合诊断)、金融(跨行反欺诈)、制造(跨工厂故障预测)、政务(隐私敏感数据共享)。
**局限**:技术复杂、运维成本高、性能仍弱于集中式训练、合规框架仍在完善中。

### 路线 E:主权云 / 本地化路线

**核心主张**:把 AI 基础设施"搬到自己家"——芯片、服务器、数据中心、训练框架、模型、应用全栈本地化。

**代表玩家**:沙特 HUMAIN(PIF 牵头,$77B+ 11 个数据中心规划);阿联酋 G42 + Stargate UAE(5 GW 园区,首期 200 MW 2026 投运);法国 Mistral + Campus AI(1.4 GW,MGX + Bpifrance + Mistral + NVIDIA + Campus AI 联合,2026 H2 启动建设,2028 年开始投运)[^ch12-15][^ch12-16];印度 IndiaAI Mission(38,000+ GPU 公共池,AdaniConneX 联邦 1 GW 在建)[^ch12-17];华为云 Stack(昇腾 910C + MindSpore + 盘古大模型 + 行业方案全栈)。

**2026 节点**:四大超大规模(Alphabet + MSFT + Meta + AMZN)2026 年合计 CapEx 约 $700B,2027 年预计 >$1T;AWS Capacity Blocks 2026-07-01 起 GPU 实例价格上涨约 200%,反映主权云需求侧的极度紧缺[^ch12-18]。

**适用场景**:对数据出境零容忍的政府/军事/金融核心场景;能源富集国家(沙特、阿联酋)将能源优势转化为 AI 主权资产;有强监管要求的行业(医疗、政务)。
**局限**:投入巨大(单 GW 数据中心投资数十亿美元);技术生态自给门槛高;规模效应弱于超大规模云。

### 五条路线对比表

| 维度 | A 开源权重 | B 闭源 API | C 开放协议 | D 联邦隐私 | E 主权云 |
|------|-----------|-----------|-----------|-----------|---------|
| **开放度** | 高(权重公开) | 低(仅 API) | 中(协议公开,实现不公开) | 中(技术公开,数据不流动) | 低(全栈私有) |
| **可控性** | 中(依赖上游) | 低(提供方主导) | 高(治理参与) | 中(技术可控,数据仍分散) | 高(全栈自持) |
| **成本** | 中(算力自担) | 低起步(订阅)、高规模(被锁定) | 中(协议治理参与成本) | 高(技术+运维双重) | 极高(GW 级投资) |
| **适用场景** | 科研/初创/定制 | 能力优先/不愿运维 | 跨国/多云/互操作 | 医疗/金融/政务/制造 | 政府/能源/军事/强监管 |
| **代表案例** | Llama 4, Mistral, DeepSeek, GLM-5 | OpenAI, Anthropic, Gemini | AAIF (A2A+MCP) | FATE, LillyTuneLab, GAIA-X | HUMAIN, Stargate UAE, 华为云 Stack |
| **2026 关键事件** | 7-24 联名信 | OpenAI 7-25 妥协 | AAIF 2026-04 成立 | AIFL-OS 性能突破 | AWS Capacity Blocks 涨价 200% |

### 选路建议:不押单一,做"路线组合"

对国家层级,几乎没有国家是单一路线。**美国**是 B 主线(A 为辅,C 是基础设施层);**中国**是 A 主线(E 是国家算力,B 是商业服务);**欧盟**是 C + D 主导(GAIA-X + AI Act,加 E 国家级超算);**中东**是 E 主线(A + B 是采购层);**印度**是 A + C + D 组合(Sarvam + Bhashini + Adani 联邦)。

对企业层级,2026 年的工程实践正在形成"**1+1+1 三件套**":一个本地开源权重(可控)、一个商业 API 备选(应对突发能力需求)、一个联邦隐私层(处理敏感数据)。这一组合在风险与成本之间形成现实平衡——纯粹押注任何单一路线,在 2026 年的"主权债积累"速度下都难以持续。
