# 《AI主权》图稿清单

> 原则：图必须帮助读者看见关系、过程、层级或变化。优先原创信息图；图量服从论证，避免把短期型号、榜单和政策状态作为长期论证骨架。书中允许同时使用两类图：
>
> - **原创信息图**：根据一手数据绘制的概念图、数据卡、流程图，标注数据来源与截至日期；用于表达机制、关系、对比和过程。
> - **网络公开图**：来自 Unsplash / 政府公共领域 / 设备厂商官方页面 / 维基百科 CC 协议的实拍图；用于提供物理直觉（数据中心的实景、芯片的实拍、电力基础设施）。每张图在正文中明确标注"来源：网络公开图 + 协议"，并由编辑在出版前逐一核验版权方是否允许纸书商用与署名方式。
>
> 默认适配单色印刷，同时准备彩色电子版。图中文字只保留必要标签，完整解释放在图题与正文。

## 设计与交付标准

- 纸书图以黑、白、灰和一种强调色仍可辨识为底线，不依赖彩虹色区分类别。
- 优先交付 SVG / PDF 矢量源文件；位图按最终版面至少 300 dpi。
- 中文字体、英文大小写、Token、Agent、AgenticOps 等术语与正文统一。
- 每张图均需图题、图注、来源 / 原创说明、版本日期和可编辑源文件。
- AI 生成图只用于概念性氛围插图，不伪装成真实人物、真实现场或历史照片；本清单第一批均优先采用可核验的原创信息图。
