# 《AI主权：智能体时代的国家竞争、企业重构与超级个体崛起》

> 当机器越来越会做事，我们怎样保住选择的能力？

中文书籍《AI主权》的书稿仓库，由 Frank Chen 主理。仓库里的拆分目录是唯一正文来源。二〇二六年十月八日全书整合改写为"序章＋三部七章＋结语＋附录"，此前的十一章稿只保留在 Git 历史中，需要时可以从那里取材。

本书的核心判断只有一句：

> **AI主权不是完全自给自足，而是在深度相互依赖中保留选择权。**

## 阅读路径

1. **序章　它替你按下了发送键**：二〇二六年七月的开放权重之争和一次 AI 入侵，引出全书的四个问题。
2. **第一部　离不开**：AI 怎样被生产出来（第一章），能力怎样变便宜、变开放又变集中（第二章），机器从回答走到行动以后，谁握着开关（第三章）。
3. **第二部　管得住**：主权在三个尺度上怎样建起来。个人（第四章），团队与企业（第五章），城市与国家（第六章）。
4. **第三部　走得了**：依赖怎样不变成支配，离开的权利怎样写进协议、审计和开放生态（第七章）。
5. **结语　把选择权留在手里**：运行中的主权，这本书可能错在哪里，以及从一项真实任务开始。

时间不够的读者可以先读序章、第三章和结语，再挑自己所在的尺度（第四至六章之一）深读。

全书只有一个虚构人物林舟，其余都是真实案例。

## 核心论点

**一、主权看运行，不看拥有。** 服务器放在自己机房、权重下载到本地，都不自动等于主权。要看系统真正跑起来时，数据有没有越过边界，权限有没有越放越大，出了问题能不能停下来、退回去。

**二、六种能力。** 选择、替换、迁移、审计、组合、演进（第三章）。

**三、四个问题。** 它能看到什么？它能做什么？谁能让它停下来？出了事谁负责？（第三章、附录D）

**四、同一套能力，三个尺度。** 个人守住意图和记忆，团队和企业守住数据边界与生产连续，城市和国家约束公共权力。这几层谁也替不了谁。

**五、离开的权利。** 依赖本身不可怕，可怕的是进得来、走不了。进入、使用、离开三个时刻都要有退路（第七章）。

协作规范见 `AGENTS.md`，文风要点见 `90_出版工作台/03_文风与改写要点.md`。

### 写进书稿的事实须标三样

- **截至日期**（YYYY-MM-DD）
- **来源 URL 与媒体**，优先级为一手来源 > 权威转述 > 二手报道
- **置信度**：已确认 / 多源一致 / 待确认 / 单一来源

脚注在正文中用 `[^key]` 引用，统一定义在 `05_附录/附录B_精选尾注.md`，不允许悬空、重复或闲置。
