# 《AI主权》结构与篇幅审计

> 审计日期：2026-08-06。只记录结构观察、处理结果与复审关注点。

## 本轮章际重构

| 原结构 | 观察 | 处理 |
|---|---|---|
| 原第一章“Token工厂” | 前半解释大模型生产，后半转入能力扩散、开放、部署与智能体网络，一章同时承担“工厂内部”和“模型离厂”两个问题 | 拆为第一章“Token工厂”5节与第二章“模型走出工厂”7节；第一部形成“生产—扩散—委托”三章链 |
| 四级主权的普通主权漂移 | 个别个人、政府与国家段落可独立用于普通隐私、公共权力或产业主权，未说明大模型带来的新增机制 | 在五个相关章导读和低锚定小节补入上下文聚合、概率生成、智能体工具调用、模型漂移与能力吸收机制；不另建平行框架 |
| 第三部只有开放生态 | 从依赖治理直接进入结语，缺少智能进入生产后对组织形态的正面展开 | 新增第十章“AI Native原生组织”，专门处理过程/产品原生、任务化分工、人机团队、层级、组织记忆、智能体岗位与人的接管责任 |
| 第四章个人与OPC交错推进 | 个人资产、代理控制与一人公司在章内反复换挡，读者尚未建立个人控制框架就被带入企业边界 | 重排为“资产与边界—代理与能力网络—最低可行控制—OPC”，内容不扩张，章末由OPC自然转入受托组织 |
| 第六章“一项生产任务的六个断点” | 同一小节同时承担现场症状、主权控制面和智能稀缺性迁移三个完整判断 | 拆为三个独立二级小节，形成“症状—架构—经济含义—运行机制”的递进 |
| 第七章“政府与国家” | 公共权力问责与国家能力积累属于同一主权层级的两种责任，但对象、时间尺度和证据类型不同，合章造成中途换题 | 拆为第七章“政府：让公共权力接受约束”和第八章“国家：让智能沉淀为共同能力”；明确两章仍共同构成第四级主权 |
| 原第八章“在依赖中保持自由” | 内容本身围绕安全—协议—开放—协同—未来形成连续链，但章号与新增国家章冲突 | 顺延为第九章，保持内容结构，补入第二部到第三部及本章到结语的桥梁 |

## 短单元观察

当前存在若干不足500字符的小节，主要分为三类：

- 章末转场，如“从Token到行动”“把智能变成企业自己的能力”；
- 理论护栏，如“技术产地不是主权结论”“谁仍是行动的作者”；
- 结语中的框架回收，如“六种能力必须接受检验”“四个层级共同构成责任链”。

这些单元在物理文件上保持独立，便于出版复审决定保留留白、并入相邻节或改为无标题过渡。当前不机械合并，以免提前消除节奏功能。

## 结构基线

- 12个章级单元；
- 144个独立正文小节；
- 章导读只承担开场，不重复全章摘要；
- 二级标题对应独立文件；三级标题只在仍服务单一论证过程时保留；
- 不建立与小节目录并行的完整章文件。
