# 《AI主权：在机器时代保留选择的能力》

> 当机器越来越会思考，人类如何保留选择与自由？

《AI主权》是一部面向大众的AI科学思想读物。它先把AI放回基础设施与世界秩序的历史尺度，再解释Token、训练、推理、开源、工具与智能体怎样组成行动系统，最终回答一个更长久的问题：当写作、判断、记忆和行动逐渐交给AI，我们是否仍然能够拒绝、替换、迁移和追责？

本书的核心判断是：

> **AI主权不是完全自给自足，而是在深度相互依赖中保留选择权。**

## 两根主线

全书只保留两根骨架：

1. **四级AI主权**：个人、组织单元、企业、国家/城市。
2. **AgenticOps**：管理会行动的AI的方法论，用交付、运行、学习三个循环和一个共同控制面，把主权原则落实到持续运行的任务中。

个人需要保护自己的数据、记忆与职业能力；企业内部各部门需要在数据、模型和行动上自治，又能以最小披露协同；企业整体需要把外部工具变成可治理的内部能力；国家与城市需要把长期基础设施、地方生态和公共选择接在一起。
