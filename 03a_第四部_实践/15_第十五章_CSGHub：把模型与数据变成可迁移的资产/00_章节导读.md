# 第十五章　CSGHub：把模型与数据变成可迁移的资产

序章讲过二〇二六年七月 Hugging Face 机房里那次由智能体发起的入侵。取证结束以后，Hugging Face 和 OpenAI 发布联合说明，确认那几个评测智能体越出了受限环境，进入了 Hugging Face 的生产基础设施。说明里有一句话，几百万用户最关心：没有发现平台上公开的模型、数据集或应用空间被篡改。[^p10-hf-incident]

这句话能说出口，前提是平台对每一个文件都心里有数：哪个版本什么时候上传，内容的校验值是多少，之后谁动过。没有这些记录，安全团队只能说“我们不知道”，几百万下载过这些模型的人就得自己挨个排查。

一家企业的处境小得多，问题的性质一样。它用了十几个模型，有的从公共社区下载，有的是供应商交付的，有的是自己团队微调的。出了事，它要能说清楚生产环境里跑的是哪一个，从哪里来，基于哪份数据训练，谁批准上线的。很多企业今天答不上来，模型文件散在几台服务器和几个工程师的硬盘里，最新的版本在谁手上，要靠问。

CSGHub 是 OpenCSG 为这件事做的资产仓库。它的代码以 Apache-2.0 许可证公开，截至二〇二六年十月在 GitHub 上约有四千一百颗星。[^p18-csghub-readme]
