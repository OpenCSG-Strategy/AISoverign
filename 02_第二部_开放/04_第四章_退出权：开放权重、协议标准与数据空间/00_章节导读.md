# 第四章　退出权：开放权重、协议标准与数据空间

二〇二五年六月十六日，AI 编程编辑器 Cursor（美国初创公司 Anysphere 的产品，据 TechCrunch 报道，当时年化收入已超过五亿美元）改了它每月二十美元的专业版套餐。原来的规则是每月五百次快速调用前沿模型，用完以后还能无限次慢速调用；新规则改成每月二十美元的额度，按模型厂商的接口价格扣，扣完要么另外付钱，要么只能用系统自动分配模型的“自动模式”。[^p7-cursor-pricing]

很多开发者是在账单上才看明白这次改动的。有人用 Anthropic 的 Claude 模型写了几轮代码，额度就见了底；有人没设消费上限，月底多出一笔没想到的费用。Cursor 的解释是，新模型做一项长任务要消耗的 Token 越来越多，这些成本原来由公司自己扛着，现在只能转给用户。用户在论坛和社交媒体上算账、抗议。科技媒体 TechCrunch 认为，Anthropic 自己的编程工具 Claude Code 很可能借机从 Cursor 那里拉走了一部分用户。Cursor 用的模型本来就是别家的，换一个入口照样能用上，开发者的“离开”是一个随时能兑现的选项。[^p7-cursor-pricing]

七月四日，Cursor 发文道歉：“我们承认这次定价调整处理得不好，对不起。”公司承诺，六月十六日到七月四日之间用户被意外收取的费用全额退还，以后改价格会说得更清楚。[^p7-cursor-pricing] 新的计费方式本身没有撤回。

Cursor 没有做违法的事，它只是改了自己产品的价格。让开发者恼火的，是他们突然看清了自己的处境：对方可以单方面改条件，自己天天用的工作环境、写好的规则文件和养成的习惯，都长在别人的产品里。Cursor 自己也站在同样的位置上。第三章讲过，Anthropic 只提前不到五天就收紧了 Windsurf 调用 Claude 的容量；模型厂商的价格和容量一变，Cursor 这样的应用就得跟着变，再把变化转给它的用户。让 Cursor 三周内道歉退款的，一半是用户的抗议，一半是用户手里真有别的去处。

前面几章已经说清楚，没有哪个人、哪家企业、哪个国家能独自造出全部的芯片、模型和数据。依赖躲不掉，我们关心的是怎样让依赖不滑向受人摆布。
