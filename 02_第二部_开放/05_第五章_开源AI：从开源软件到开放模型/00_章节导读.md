# 第八章　从开源软件到开源 AI：一场生产方式的迁移

二〇二五年五月一日，内存数据库 Redis 的同名公司发布了 Redis 8，同时给它加上了 GNU Affero 通用公共许可证第三版（AGPLv3）这个选项。AGPL 在开放源代码促进会（Open Source Initiative，OSI，负责审定开源许可证的美国非营利组织）认可的开源许可证名单上，Redis 由此重新成为开源软件。公司首席执行官罗恩·特罗洛普（Rowan Trollope）在公告里承认，一年前那次改许可证“伤害了我们和 Redis 社区的关系”。[^p8-redis-agpl]

一年前，Redis 公司宣布新版本不再使用宽松的 BSD 许可证，改用两种不许别人拿它做托管服务的源代码可用许可证；八天后，Linux 基金会（Linux Foundation，托管 Linux 等大量开源项目的非营利组织）就拿仍是 BSD 授权的旧代码另起炉灶，成立了分叉项目 Valkey，亚马逊云科技（AWS）、谷歌云和甲骨文等公司表态支持。[^p8-valkey] 此后的事情发生得很快。二〇二四年十月八日，AWS 推出基于 Valkey 的托管缓存服务，无服务器版的定价比它支持的其他引擎低百分之三十三，按节点计费的低百分之二十，老客户换过去还能保留原来的预留折扣。[^p8-elasticache-valkey] 特罗洛普后来对科技媒体 The New Stack 说，改许可证只算“中等成功”：微软买了授权，亚马逊和谷歌都没有买。[^p8-redis-agpl]

Redis 公司有权决定以后怎样卖自己的产品。它没法做到的，是让用户从此只能跟着它走。已经以 BSD 发布的代码收不回来，社区里有足够多懂这套代码的工程师，再加上一家中立的基金会愿意出面，分叉就成立了。分叉站稳以后，原厂自己也回到了开源许可证上。

开源在主权问题上的分量，在这种时候看得最清楚。到了 AI 时代，一个系统除了代码，还有权重、训练数据和评测方法，“开源”这个词也跟着变得复杂起来。
