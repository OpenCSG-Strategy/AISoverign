# 《AI主权：在机器时代保留选择的能力》

> 当机器越来越会思考，人类如何保留选择与自由？

《AI主权》是一部面向大众的AI科学思想读物。它先把AI放回基础设施与世界秩序的历史尺度，再解释Token、训练、推理、开源、工具与智能体怎样组成行动系统，最终回答一个更长久的问题：当写作、判断、记忆和行动逐渐交给AI，我们是否仍然能够拒绝、替换、迁移和追责？

本书的核心判断是：

> **AI主权不是完全自给自足，而是在深度相互依赖中保留选择权。**

## 两根主线

全书只保留两根骨架：

1. **四级AI主权**：个人、组织、企业、政府/国家。
2. **AgenticOps**：管理会行动的AI的方法，分别嵌入四个层级，而不是单独成为一本工程手册。

个人需要保护自己的数据、记忆与职业能力；学校、医院和公益组织需要替共同体守住边界；企业需要把外部工具变成可治理的内部能力；政府与国家需要维护公共选择与长期基础设施。
