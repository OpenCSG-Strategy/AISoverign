# 《AI主权》出版标注规范

> 本目录服务编辑、设计、审校与组装，不进入纸书正文。

## 一、书稿单元

- **章级单元**：每章目录中的 `00_章节导读.md`，以一级标题写章题，后接开场。
- **小节单元**：每个二级标题单独一个 Markdown 文件，文件以该二级标题开头；三级标题留在所属小节内。
- **部导读**：每部目录下的 `00_第X部导读.md`，以一级标题写部名。
- **辅文单元**：书前、附录与出版工作台不强制拆分，按实际出版功能管理。

文件名用两位数字前缀决定顺序，改标题时同步改文件名和 `00_书前/03_目录.md`。正文文件不加 YAML 元数据。

## 二、出版状态

统一使用以下状态，记在 `.content-index.md` 中，不使用"差不多""基本完成"等模糊说法：

1. `待出版初审`：结构已定，尚未完成出版社口径初审。
2. `初审已修`：内容、导向、版权和事实问题已按初审意见处理。
3. `复审已修`：语言、术语、标题层级、图表和注释体例已统一。
4. `终审待定`：只剩作者、出版社或装帧层面的确认项。
5. `出版冻结`：正文、图表、尾注与版式引用均已锁定；新事实不再直接写入。

若一章只有部分小节通过审校，章级状态取该章中最早的未完成阶段。

## 三、章级出版检查

- 本章只承担一个核心任务，开场的案例和结尾的判断能够闭合；
- 小节顺序形成递进，不依赖"如前所述"维持结构；
- 案例、技术解释和论证的节奏不过度集中；
- 本章图号连续，图题、正文提及和图稿清单一致；
- 所有脚注在附录B有唯一定义；
- 与前后章没有重复定义或结论抢跑。

## 四、小节出版检查

- 一个小节只承担一个主要判断；
- 技术术语首次出现有日常语言解释；
- 外国机构和人名首次出现有英文原名和身份说明；
- 事实具有来源、截至日期和适当的置信边界；
- 案例不把项目方口径写成普遍结论；
- 配图必须减少理解成本，不能只是装饰。

文风细则见 `03_文风与改写要点.md`。

## 五、图稿

正文直接用 Markdown 图片链接引用 `assets/figures/` 下的 SVG，图题写在方括号里，格式为"图 X-Y　图题"。图号、位置和生成方式统一维护在 `02_图稿清单.md`。

## 六、组装与校验

`tools/book_structure.py` 是正式结构工具：

- `validate` 检查部导读、章目录、小节编号与标题层级、图片链接和脚注配对；
- `assemble <输出路径>` 按正式顺序组装连续正文，并把图片链接改写为相对输出文件的路径。

提交前须 `validate` 结果为 `0 failures`。
