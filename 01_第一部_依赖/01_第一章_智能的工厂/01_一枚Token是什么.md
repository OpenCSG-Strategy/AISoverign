## 一枚 Token 是什么

你在输入框里打的是一句话，模型收到的是一串编号。

文字送进模型以前，有一个叫分词器的程序先把它切成小块，再把每一块换成词表里的一个数字。这些小块叫 Token，中文常译作"词元"。一枚 Token 可能是一个汉字，也可能是半个英文单词、一个标点或者一段空格。不同模型的切法不一样，同一句话在不同模型里会被切成不同数量的 Token。[^p1-tokenizer]

大语言模型做的事情说起来很简单：看着前面已经有的 Token，猜下一个最合适的 Token 是什么；猜出一个，接上去，再猜下一个。一篇报告、一段对话、一段程序，都是这样一个一个接出来的。

有人因此把大模型叫作"高级自动补全"，这低估了它。模型在训练中见过海量文字，参数里积累下了大量可以迁移的规律，所以能翻译、写摘要、写代码，也能处理训练材料里从没逐字出现过的新问题。不过它的工作方式始终是先生成一段在上下文里读起来合适的文字，并不会先去现实世界核实每一句话。同一套机制，可以让它写出人没预先编好的好答案，也可以让它把真实的人名、专业的口吻和编造的事实组合成一段很有说服力的假话。

Token 也是今天 AI 行业的计量单位。模型公司按 Token 收费，数据中心按每秒生成多少 Token 报产能，国家部门也开始用 Token 来统计 AI 的使用规模。就像电力按千瓦时计量一样，AI 正在被当成一种按单位生产、按单位计费的公共产品。[^p1-ai-factory]

可 Token 只是中间产品。模型生成了一万个 Token，如果专家还得从头重做一遍，这一万个 Token 就是返工成本，算不上产出。
