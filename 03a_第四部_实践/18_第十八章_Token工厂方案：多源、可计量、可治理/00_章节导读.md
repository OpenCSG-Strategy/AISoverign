# 第十八章　Token 工厂方案：多源、可计量、可治理

2026年6月10日，北京经济技术开发区（亦庄）的“北京壹号词元工厂”投入运行。词元就是Token。按北京市人民政府网站和国家科技传播中心的报道，它一期每天能生产1.4万多亿个Token，远期目标是每天10万亿个；一半的任务在6秒内完成，90%在10秒内响应，性能波动控制在20%以内。报道称，和它一起发布并开源的，还有国内首套Token工厂性能基准。[^p21-beijing-token-factory]

这几个数字里没有一个是GPU的张数。第一章开头讲过xAI在孟菲斯装下10万张英伟达芯片的Colossus，那时候算力中心报的是卡数、机柜数和用电量。[^p1-token-factory-builds]两年以后，北京这座工厂对外报的是产量和响应时间。报道特意说，它和出租算力卡的机房不同，提供的是用算力生产Token的软件服务。

计量单位换了，买卖双方谈的东西也就换了。按卡和时长收费，算力用得好不好是客户的事；按Token收费，厂家要对生产效率负责；再往前走一步，客户最终要买的是一件完成了、验过了的任务。第一章用“Token工厂”指从接到问题到交出结果的整条生产线。这条生产线可以成为城市和企业手里的基础设施，也可能变成一个新的集中依赖点，差别在于建的时候有没有留下替换、计量和治理的余地。

在OpenCSG的方案里，Token工厂是几样东西的组合，没有哪台机器或哪款软件能单独卖给客户：底下是客户自己或者合作方的异构算力，中间是CSGHub承担的模型服务、模型网关、路由和计量，上面是AgenticHub承载的智能体任务，再加上一套评测和数据流程把结果接回来。拿这套组合当案例，可以看清一座Token工厂怎样才算城市和企业自己的基础设施。
